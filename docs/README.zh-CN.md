# digital minimalism：数字极简主义

**让代币休眠，让生活继续。**

项目名 digital minimalism 全小写，代币名 DM 全大写。项目以 Offline 为核心。用户自愿存入部分代币，按数量与休眠时间分享实际注入的 ETH，随时取回本金，没有固定期限、退出费、惩罚或签到。

## 规则

- 权重 = 当前存入代币的累计 token-seconds；只在注资时分配奖励。
- 追加代币从零计时，不继承原有代币的时长。
- 部分取回按比例移除时间权重；全额取回清空活跃权重，但保留已赚奖励。
- 领取 ETH 不重置时长。重新存入从新时间开始。
- 时间权重没有上限；较早参与者可能拥有明显高于新参与者的权重。
- 无实际 ETH 注资就没有新增奖励；不是固定 APY，也不证明用户本人断网。

Stockereum 正常交易费 3%，其中平台 1%、创作者 2%。创作者手动领取 WETH、解包 ETH，再注入奖励合约。平台原生 Holder Rewards 关闭。开盘反抢跑阶段的临时高费率另行适用。
